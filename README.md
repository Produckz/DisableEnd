# Disable End

A lightweight, server-side Fabric mod that adds a gamerule to disable the end. With the rule on, end portals simply stop working, so you can gate the dragon fight behind an event or keep the end closed on a new server.

## Gamerule

`/gamerule disable_end <true|false>` -- blocks end portal teleportation while true (default false).

Portals still generate and activate as normal, but players do not get teleported. Turn the rule off and portals will work again instantly.
